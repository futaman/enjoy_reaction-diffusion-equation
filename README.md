# 草とウサギで模様をつくる ―― 反応拡散ドリル

中学数学レベルの人が、反応拡散方程式（Gray-Scott モデル）を少しずつ理解して、**好きな模様を自分で作れるようになる**ための、HTML のドリルです。

**▶ 公開ページ：https://futaman.github.io/enjoy_reaction-diffusion-equation/**

草（u）とウサギ（v）のたとえで、式を1項ずつ組み立てていきます。どの章にも、触って確かめられるデモと、すぐ答え合わせができる問題があります。

```
∂u/∂t = Du∇²u − uv² + F(1−u)
∂v/∂t = Dv∇²v + uv² − (F+k)v
```

## 中身

| 章 | テーマ | できるようになること |
|---|---|---|
| はじめに | 模様は計算で作れる | 動く模様を見て、草とウサギに出会う |
| 第1章 | 変化の速さ | 「新しい値 ＝ 今の値 ＋ 速さ × 時間」が使える |
| 第2章 | 記号 ∂u/∂t と「場」 | 場所ごとの値の地図と、その場所での変化の速さがわかる |
| 第3章 | 拡散（1列のマス） | 「となりの平均に近づく」ルールで手計算できる。Δt を大きくしすぎると壊れることを知る |
| 第4章 | 記号 ∇² と2次元の拡散 | ∇² を「まわりの平均 − 自分」として計算できる |
| 第5章 | 反応の項 | 草とウサギのルール（生える・食べて増える・減る）を説明できる |
| 第6章 | 全部を合わせる | 1マスを手で1コマ進め、コンピュータと答えが一致することを確かめる |
| 第7章 | 模様ができる理由と、模様の地図 | 模様ができる理由を説明できる。F-k マップで狙った模様を出せる（再現チャレンジ） |
| 第8章 | 自由ラボ | ウサギを描いて、好きな模様を作り、画像やコレクションに残す |

- 問題には、3段階のヒント、まちがえた選択肢ごとの説明、「答えを見る」があります。
- 章ごとのクリア（✓）と、再現した模様のコレクションがあります。どの章からでも開けます。
- 各章の終わりに、教える人向けの「先生用メモ」（折りたたみ）があります。
- 明るい表示と暗い表示に対応し、スマホでも使えます。

## 使い方

- **公開ページ**を開くか、`dist/index.html` をブラウザで開くだけで動きます。
  - HTML ファイル1つ（約450KB）で、外部のライブラリやフォントは読み込みません。オフラインでも動きます。
  - メールや USB でそのまま渡せます。
- **進み具合とコレクション**は、そのブラウザの中に保存されます。別のブラウザや端末、別の場所に置いたファイルで開くと、最初からになります。
- スマホでは、ファイルのプレビュー表示ではなく、Chrome や Safari などのブラウザで開いてください。
- 比較的新しいブラウザが必要です（目安：Chrome / Edge 111 以降、Safari 16.2 以降）。

## 開発

必要なのは Node.js 22 だけです（npm パッケージのインストールは不要）。ブラウザでの確認には Playwright を使います。

```bash
node build.mjs                 # src/ → dist/index.html（1ファイルにまとめる）
npm test                       # エンジンと各章の問題の答え・本文の主張を検算（Node のテスト）
npm run smoke                  # ビルドして、全ページを PC 幅と 360px で開き、エラーと横はみ出しを確認
node tools/verify-params.mjs   # 模様のパラメータを検証（数分かかる。結果は tools/out/）
```

- 一部の章だけをビルド：`node build.mjs --out tmp/a.html --chapters ch3,ch4`
- 一部の章だけを確認：`node tests/smoke.mjs --file tmp/a.html --shots tmp/shots ch3 ch4`
  - スクリーンショットは `tests/out/`（または `--shots` で指定した場所）に出ます。
- **公開：** `main` に push すると、GitHub Actions（`.github/workflows/pages.yml`）がテスト → ビルド → GitHub Pages への公開まで行います。

### 計算の約束

- ∇² は、この教材では「上下左右4マスの平均 − 自分」と定義しています。手計算とシミュレーションは、同じこの定義で計算します。
- 時間の刻みは Δt = 0.8（Du = 1.0、Dv = 0.5）です。D × Δt が 1 ちょうどだと壊れるので、少し余裕を持たせています。
- 模様の値と合格範囲は、教材と同じ計算で検証して決めています（`docs/param-report.md`）。
