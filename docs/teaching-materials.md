## T：つまずきポイント

### 記号と微分

| ID | つまずき | 起きがちな誤解 | 対策 |
|---|---|---|---|
| ★T01 | 式は「値」ではなく「変化のルール」 | `∂u/∂t = 3` を「u = 3」と読む | 「新しい値 = 今の値 + 速さ × 時間」を何度も手で回す。式は「次のコマを作るルール」 |
| ★T02 | u は1つの数ではなく「場所ごとの値の地図（場）」 | u を x のような普通の変数だと思う | 天気図の気温マップ。マス目のどこをクリックしても u, v が見える |
| T03 | ∂ と d の違いが気になる | 難しい記号に身構える | 「場所を固定して、時間の変化だけ見る」と言い切る。各地点の温度計 |
| ★T04 | ∇² の正体 | 「2回微分」で思考停止 | 先に「∇²u = まわりの平均 − 自分」と定義してしまう。2回微分との関係は「もっと詳しく」へ |
| T05 | ∇² の符号の向き | 「まわりより低いと減る」と逆に覚える | 地形。谷底（まわりより低い）は埋まる＝プラス、山頂は削られる＝マイナス |
| T06 | 連続とコマ送り | 「シミュレーションは嘘」 | パラパラ漫画。コマを細かくすると本物に近づくデモ |

## A：たとえ話

### メインのたとえ：草とウサギ（決定）

教材全体を通して、このキャラ設定に統一する。

| 式の中のもの | たとえ |
|---|---|
| u | 草の量（0〜1。1が満タン） |
| v | ウサギの数（濃さ） |
| Du∇²u | 草のタネが風で広がる（速い） |
| Dv∇²v | ウサギが歩いて広がる（遅い） |
| F(1−u) | 草が生えてくる（満タンまでの残りに比例） |
| uv² | ウサギはペアで草を食べて増える |
| kv | ウサギの寿命 |
| Fv | 草原の入れ替え（かけ流し）でウサギも流される ※「もっと詳しく」で水槽のたとえを使って補足 |

**限界:** Fv（ウサギも流される）は草とウサギでは不自然。ここだけ A11（水槽のかけ流し）に切り替えると明示する。

### 動機づけの話題

- **チューリング（1952）:** コンピュータの父が「生き物の模様は化学反応で作れる」と予言した。
- **近藤滋さんら（1995）:** タテジマキンチャクダイの縞が、成長すると予言どおりに増えることを確かめた。
- **身近な実例:** シマウマ、ヒョウ、指紋、貝殻、サンゴ。
- **Pearson（1993）:** Gray-Scott モデルの模様を分類した研究。F-k マップの元ネタ。
