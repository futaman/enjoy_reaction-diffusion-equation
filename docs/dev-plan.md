# 開発計画

## 方針

- 開発中はファイルを分けて書き、`build.mjs` で **HTML ファイル1つ**（`dist/index.html`）にまとめる。外部依存はゼロ。
- 共通部品（core）の API を先に固め、章ごとの実装は複数のエージェントで並行して進める。
- 各章のファイルは担当者だけが書く。core に変更が必要になったときは、統括（メイン）が引き取る。

## ディレクトリ

```
src/
  index.template.html   シェル（<!--STYLES--> と <!--SCRIPTS--> を build で差し込む）
  styles/base.css       デザイントークン、レイアウト、共通部品の見た目
  core/                 共通部品（読み込み順は build.mjs の CORE_ORDER）
    ui.js               h() ヘルパー、解説・もっと詳しく・先生用メモ・つまみ・数値マス
    store.js            localStorage ラッパー（失敗しても動く）
    sim.js              Gray-Scott エンジン（0次元・1次元・2次元、項のオン・オフ）
    patterns.js         模様のプリセット（F, k, 種の置き方、合格領域）
    views.js            草原ビュー（キャンバス）、棒グラフ、時間グラフ、カラーバー
    ledger.js           1マスの家計簿
    equation.js         色分けした式（項クリックでオン・オフ）
    quiz.js             問題（選択、数値、マス、対応づけ、穴埋め、カスタム）、ヒント3段階
    calc.js             電卓
    app.js              ルーター、章の登録、トップページ、進み具合、コレクション
  chapters/             1章1ファイル。RD.registerChapter() で登録
tests/                  Node テスト（エンジン、問題の答え）、Playwright スモークテスト
tools/                  パラメータ検証スクリプトなど
dist/index.html         配布物
```

## フェーズと担当

| フェーズ | 内容 | 担当 | 並行 |
|---|---|---|---|
| 0 | 計画、ディレクトリ、build | 統括 | ― |
| 1a | core 一式 ＋ 章のお手本（プロローグ） | 統括 | 1b と並行 |
| 1b | 模様パラメータの検証（この教材の ∇² の定義で F-k の値と合格領域を確定し、patterns.js を書く） | エージェント「パラメータ検証」 | 1a と並行 |
| 2 | 章の実装 | 下の4エージェント | 4本並行 |
| 3 | 結合、テスト、見た目の確認、修正 | 統括 ＋ エージェント「QA」 | ― |

### フェーズ2の担当割り

| エージェント | 担当ファイル | 主な中身 |
|---|---|---|
| 章A | `chapters/ch1.js`, `chapters/ch2.js` | 変化の速さ、∂u/∂t と場 |
| 章B | `chapters/ch3.js`, `chapters/ch4.js` | 1次元の拡散、∇² と2次元の拡散 |
| 章C | `chapters/ch5.js`, `chapters/ch6.js` | 反応の項、全部を合わせる（手計算） |
| 章D | `chapters/ch7.js`, `chapters/ch8.js` | 模様の謎と地図、再現チャレンジ、自由ラボ |

### 各章の完了条件

- 仕様書（spec.md）のその章の項目（ねらい、デモ、ドリル、クリア条件、先生用メモ）がすべて入っている
- 問題の正解は `tests/` で自動検算する（手計算の問題は、エンジンの計算結果と一致すること）
- ビルド後、Playwright でコンソールエラーがない。横幅 360px で横スクロールが出ない

## ルール

- 文言はです・ます調で、中学生に話しかけるやさしい言い回しにする。漢字には必要に応じてルビ（`<ruby>`）を振る。
- 式は `RD.ui.math()` を使い、項の色は `t-diff`（青）、`t-feed`（緑）、`t-react`（オレンジ）、`t-decay`（紫）のクラスで統一する。
- 草とウサギのたとえを崩さない。Fv だけは水槽のたとえで補足する。
