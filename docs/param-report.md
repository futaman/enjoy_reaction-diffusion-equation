# パラメータ検証レポート

`tools/verify-params.mjs`（Node 22、依存なし）で、教材と同じ離散化を使って確かめた結果です。
スナップショットは `tools/out/*.png` にあります（色は v の濃さで、暗いほど v が小さい）。

- ∇²u = 上下左右4マスの平均 − 自分（周期境界）、オイラー法
- Du = 1.0、Dv = 0.5、格子 192×192（128×128 でも同じ模様になることを確認）
- 種の置き方は `src/core/sim.js` の `Sim.seed()` と同じにしてある
  - 正方形の種：半径 r = max(3, round(N/24))（192 なら 17×17 マス）、u = 0.5、v = 0.25
  - `center`：まん中に1つ／`random`：max(4, round(N²/2500)) 個（192 なら 15 個）／`noise`：小さめの正方形 max(8, round(N²/1200)) 個と ±0.025 のノイズ
- 再実行：`node tools/verify-params.mjs`（全部、約3分）。`presets` `seeds` `boxes` `dt` `diff` `special` `perf` `scan` `adhoc` で個別に実行できる。

## 1. dt：0.8 を推奨

| dt | 結果 |
|---|---|
| 1.0 | **6つの模様すべてで壊れる**（数百コマで市松模様が育って NaN） |
| 0.9 | 動く。0.8 と同じ模様になる |
| 0.8 | 動く。**推奨** |

- 理由：市松模様（となりのマスと交互に＋−）の成分は、1コマで u が (1 − 2·Du·dt − dt·(F + v²)) 倍になる。拡散だけなら Du·dt = 1 で倍率は −1（減りも増えもしない）だが、「草が生える」項などが加わると絶対値が1を超えて増えていく。
- 拡散だけの確認（u に 1% の市松模様、v = 0、F = 0.03、50コマ後）：dt = 1.0 で 4.4% に**増える**、dt = 0.9 で 7×10⁻⁷、dt = 0.8 で 3×10⁻⁸ に減る。
- dt = 0.8 のとき、Du は 1.2 まで安定、Du = 1.25（Du·dt = 1）で壊れる。ラボの Du つまみの上限は 1.2 以下にするか、dt を min(0.8, 0.95/max(Du, Dv)) のように自動で下げるとよい。
- dt = 0.9 と 0.8 で同じ模様になる（時間刻みとして十分小さい）。0.8 は余裕をとった値。

**仕様書の修正点：** 「安定する条件は D × dt ≤ 1」は拡散だけの場合の境目で、ちょうど 1 だと市松模様が消えずに残り、反応の項が入ると壊れる。教材では「D × dt < 1（少し余裕をもたせる）」と書くのが正確。第3章の「わざと壊す」デモは D × dt = 1.05 くらいにすると拡散だけでもはっきり壊れる。

## 2. 模様のプリセット（確定値）

ステップ数は dt = 0.8、192×192、推奨の種での目安（v > 0.2 のマスの割合が最終値の 90% に達するまで）。

| id | 模様 | F | k | 種 | 形になるまで | 合格ボックス F | 合格ボックス k | 分類 |
|---|---|---|---|---|---|---|---|---|
| mitosis | 分裂する点 | **0.037** | **0.0645** | random | 約 6000 | 0.035〜0.039 | 0.0637〜0.0648 | 止まる（※） |
| spots | 水玉 | 0.030 | 0.062 | random | 約 3000〜4000 | 0.028〜0.033 | 0.0616〜0.0628 | 止まる |
| maze | 迷路 | 0.029 | 0.057 | random | 約 1500〜2500 | 0.0275〜0.0305 | 0.0563〜0.0577 | 止まる |
| coral | サンゴ/しま | 0.0545 | 0.062 | center | 約 10000 | 0.051〜0.058 | 0.0613〜0.0627 | 止まる |
| holes | 穴あき | **0.035** | **0.0572** | random | 約 1500〜2000 | 0.034〜0.036 | 0.0569〜0.0576 | 止まる |
| spiral | うずまき・波 | **0.014** | **0.0505** | random | 約 1000〜2000 | 0.012〜0.016 | 0.049〜0.052 | 動き続ける |

太字は候補から変えた値。各ボックスは角4点・辺の中点4点・中心の 9 点を 10000 コマ回して、すべて同じ種類の模様になることを確かめた（`tools/out/box-*.png`。行が F、列が k）。水玉・迷路・穴あきは乱数の種を変えた2回でも確認した。

### 候補から変えた点と、わかったこと

- **分裂する点**（候補 0.0367 / 0.0649）：全滅との境目にほとんど接している。F = 0.036、k = 0.065 では種が消える。k を少し下げて 0.0645 にした。
  - ※**「生きている模様」ではなかった。** 点は分かれて増えるが、画面がうまる（約 8000 コマ、点が 144 個）と止まり、その後 30000 コマまで点の数は変わらない。止まった後の見た目は水玉とほぼ同じ。そこで `kind: 'still'` にした。分裂のようすを見せるなら途中の時間を見せる。center の種だと分裂しながら輪になって広がり、1万コマ以上かかるので分裂を長く見られるが、k = 0.064 以下では点ではなく輪や十字になりやすく、F が小さいと消えることもあるので、合格判定には random を使う。
  - 水玉（0.030 / 0.062）も同じしくみで増える（center の種だと分裂しながら広がる）。この2つの違いは「増える速さ」と「全滅の境目に近いかどうか」くらいしかない。再現チャレンジで両方を出すなら、完成した絵ではなく途中経過（またはアニメーション）を見せるのがよい。
- **穴あき**（候補 0.039 / 0.058）：すぐ隣（F = 0.040）が「一面同じ色」の領域で、F を少し上げると穴が消える。穴あきは「一様」と「迷路」の間の、**斜めに細い帯**（k が F に合わせて上がる）にしかできないので、帯のまん中の 0.035 / 0.0572 に移した。ボックスの角では「穴が少しまばら」「穴が少し細長い」になるが、穴あきとは見分けられる。
- **うずまき・波**（候補 F 0.014〜0.018、k 0.045〜0.054）：k = 0.045〜0.047（F ≦ 0.016）では、種から出た波どうしがぶつかって消え、**数千コマで全滅することが多い**。k = 0.049〜0.052 なら、どの種でも三日月形の波が動き回り、端がくるっと巻く（小さなうずまき）模様がずっと続く。きれいな大きいうずまきは、ふつうの3種類の種では安定して出なかった。
- **迷路・サンゴ・水玉**：候補の値のままでよい。サンゴは種を center にすると枝分かれしながら広がる「サンゴ」、random にすると「しま（ミミズ模様）」になる。迷路とサンゴは random だと完成した見た目が似ている（サンゴの方が線が太い）。

### 合格ボックスの大きさについて

- F 方向は ±0.001〜0.0035 とれるが、**k 方向は ±0.0004〜0.0015 しかとれない**。k を 0.001 動かすだけで模様が変わる（水玉→迷路、穴あき→一様など）。
- 穴あきと迷路は帯が斜めなので、四角いボックスを大きくすると隣の模様が入る。
- UI の提案：k のつまみは 0.0001 刻み、F は 0.0005 刻みにする。F-k マップは F 0.01〜0.06、k 0.045〜0.07 くらいに拡大して見せる。
- 合格判定に `sim.stats()` の cover（v > 0.2 の割合）を足すと、ボックスを広げても誤判定しにくい。目安：分裂する点・水玉 0.18〜0.29、迷路 0.33〜0.51、サンゴ 0.15〜0.6（center の種は成長中なので小さい）、穴あき 0.54〜0.87、うずまき 0.07〜0.18（動くので揺れる）。

## 3. 種の置き方の違い（`tools/out/seeds.png`、10000 コマ。列が center / random / noise）

- 水玉・迷路・穴あきは、どの種でも同じ種類の模様になる（第7章の T17「種を変えても模様の種類は変わらない」の実験に使える）。center は広がるのに時間がかかる。
- サンゴは center だけが「サンゴらしい」枝分かれになる。
- うずまきの値（0.014 / 0.0505）では、どの種でも動き回る波になる。center だと最初は上下左右に対称な形から始まる。
- 分裂する点は center だと 10000 コマ時点でまだ広がっている途中。

## 4. 教材用の特別な点（`tools/out/special.png`）

| 点 | F | k | どうなるか |
|---|---|---|---|
| 全滅 | 0.030 | 0.070 | 500 コマ以内にウサギが消え、草だけ（u = 1、v = 0）の一様な状態になる |

ほかに、F = 0.020 / k = 0.068、F = 0.050 / k = 0.072、F = 0.005 / k = 0.040 も全滅。F = 0.080 / k = 0.045、F = 0.040 / k = 0.045、F = 0.030 / k = 0.040 も一様になる。

## 5. Du と Dv の実験（`tools/out/diffusion.png`。種は random、10000 コマ）

- **Du = Dv（0.5 と 0.5、1.0 と 1.0）：模様は消える。** ただし「なめらかに一様になる」のではなく、5つの模様の値すべてで、**500 コマ以内にウサギが全滅**して草だけになる。うずまきの値（F = 0.014）でも全滅。試した中では F = 0.027 と 0.040（k = 0.045 と 0.0505）のとき、逆にウサギが一面に広がって一様になる。どちらにしても模様はできない。教材では「Du = Dv にすると模様ができない（全滅するか、一面同じになる）」と書くのが正確。
- **D を両方小さくする（比 Du : Dv = 2 : 1 のまま）：模様は細かくなる。** Du = 0.5 / Dv = 0.25 で水玉の数は約 2 倍（156 → 313 個）、Du = 0.25 / Dv = 0.125 で約 4 倍（651 個）。模様の間隔は √D に比例する（D を半分にすると間隔は約 0.7 倍）。模様の種類は変わらない。ただし D を小さくすると広がるのが遅くなり、Du = 0.25 では 10000 コマでも画面がうまりきらないことがある。

## 6. 速さ（Node 22、1スレッド、Float32Array）

| 格子 | ステップ/秒 | 60fps のとき1フレームあたり |
|---|---|---|
| 128×128 | 約 5800〜7600 | 約 100〜130 |
| 192×192 | 約 3300〜3500 | 約 55 |
| 256×256 | 約 1700〜1800 | 約 30 |

- ブラウザの JS エンジン（V8）でも同じくらいの速さのはず。ただし描画とスマホの遅さを考えると、192×192 で 1フレームあたり 20〜30 ステップが現実的。
- その場合、サンゴ（10000 コマ）は 6〜8 秒、迷路（2500 コマ）は 2 秒くらいで形になる。
- **推奨の格子は 192×192**。遅い端末では 128×128 に落とす（同じ値で同じ模様になる。点や線の太さは同じで、数が減るだけ）。WebGL は必要なさそう。
