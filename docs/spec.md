## 1. 決定事項

| 項目 | 決定 |

| 対象 | 中学数学レベル。微分は「何となく知っている」程度 |

| 使い方 | 先生が横について教えるのが基本。一人でも進められるようにする |

## 2. ゴールの式

```
∂u/∂t = Du∇²u − uv² + F(1−u)
∂v/∂t = Dv∇²v + uv² − (F+k)v
```

| 記号 | 意味（草とウサギ） | 色（M05） |
|---|---|---|
| Du∇²u, Dv∇²v | 広がる（拡散） | 青 |
| F(1−u) | 草が生える | 緑 |
| uv² | ウサギがペアで草を食べて増える | オレンジ |
| (F+k)v | ウサギが減る（流される＋寿命） | 紫 |

### この教材での ∇² の定義

**∇²u = 上下左右4マスの平均 − 自分**（1次元では左右2マスの平均 − 自分）

- 手計算でもシミュレーションでも、この同じ定義を使う。
- 本来の5点差分ラプラシアンの 1/4 にあたる。格子の間隔などの定数は D に含めたと考える。この点は「もっと詳しく」で説明する。
- この定義なら、時間を進めても安定する条件は **D × dt < 1** になる（第3章の「わざと壊す」デモで使う）。ちょうど 1 だとマス目状の揺れが消えず、反応の項が加わると壊れる。そのため既定値は dt = 0.8 にする（docs/param-report.md）。

## 3. 章構成

全体の流れは、プロローグ → 1〜6章（式を1つずつ組み立てる） → 7章（模様の謎を解き、地図で狙う） → 8章（自由ラボ）。

各章の作りは共通で、以下の順に並ぶ。

1. ねらい（1行）
2. 解説：短い本文と「もっと詳しく」（M12）
3. デモ
4. ドリル：3〜6問。ヒントは3段階、誤答ごとに説明を返す（M09）
5. クリア条件
6. 先生用メモ（M10、折りたたみ）

### プロローグ：模様は計算で作れる

- **ねらい:** 「やってみたい」と思ってもらう（T24）。
- **内容:** 完成した模様が動くデモ（水玉、しま、迷路、分裂する点）を見せる。シマウマ、ヒョウ、熱帯魚の模様を言葉で紹介し、チューリングの予言と近藤さんの研究の話をする。
- **登場人物紹介:** 草（u）とウサギ（v）。「この2つのルールだけで模様ができる。最後には自分で作れるようになる」と伝える。
- **ドリル:** なし。クリック1回で第1章へ。

### 第1章：変化の速さ

- **ねらい:** 「新しい値 = 今の値 + 速さ × 時間」が使えるようになる。
- **つまずき:** ★T01, T06
- **たとえ:** A01（貯金箱の帳簿）、A03（パラパラ漫画）
- **仕掛け:** M06（1コマ送り）
- **デモ:** 草原1か所の草の量をグラフで表示する。速さのつまみと時間の刻みのつまみを付け、1コマ送りで「帳簿」と「残高」が並んで進む様子を見せる。
- **ドリル例:**
  1. 「貯金が 500 円、1日に +30 円。3日後は？」
  2. 「草が 0.4、速さは毎秒 −0.1。0.5 秒後は？」
  3. 帳簿と残高の区別：「速さが 0 のとき、草の量は 0？」（誤答の選択肢で T01 を突く）
  4. 予告問題：「草は満タン（1）までの残りの1割ずつ増える。今 0.2 なら、1コマ後は？」（答え 0.28。第5章の F(1−u) の伏線）
- **クリア:** 4問正解。
- **先生用メモ:** 「速さ」と「量」を指でさし分けさせる。グラフの傾きが速さだと気づいたらほめる。

### 第2章：記号 ∂u/∂t と「場」

- **ねらい:** u は場所ごとに値を持つ地図であり、∂u/∂t は「その場所での変化の速さ」だとわかる。
- **つまずき:** ★T02, T03, T01（復習）
- **たとえ:** A02（各地点の温度計）、A01
- **仕掛け:** M02（1マスの家計簿を初めて使う）
- **デモ:** 5×5 の草原。マスごとに草の量を色で表示し、クリックするとそのマスの u と ∂u/∂t が出る。
- **ドリル例:**
  1. 「u = 5、∂u/∂t = −2、時間の刻み 0.5。1コマ後の u は？」（答え 4）
  2. 3×3 の u の地図と ∂u/∂t の地図を見て、1コマ後の地図を埋める（マス入力）
  3. 「∂ の意味として正しいのは？」（場所を固定して時間だけを見る、を選ぶ）
- **クリア:** 全問正解。
- **先生用メモ:** d と ∂ の違いは深入りしなくていい。「場所ごとに温度計」の一言で十分。

### 第3章：拡散（1列のマス）

- **ねらい:** 「隣との平均に近づく」という拡散のルールで、手計算ができる。
- **つまずき:** T09, T19, T06
- **たとえ:** A04（ミルク）、A05（おすそ分けルール）、A15（配りすぎ）
- **仕掛け:** M07（1次元から始める）、M11（粒の見方と値の見方を並べる）、M08（わざと壊す）、M03
- **ルール:** 新しい値 = 今の値 + D × (隣の平均 − 自分) × dt
- **デモ:**
  - 1列20マスの棒グラフ。真ん中に山を置くと、ならされていく。
  - 左右に「粒がランダムに動く」表示と「値の棒グラフ」を並べる。
  - D × dt を 1 より大きくすると、平均を通り越してシーソーのように揺れ、爆発する（配りすぎ）。
- **ドリル例:**
  1. 「隣が 10 と 20、自分が 12、D × dt = 0.5。次の値は？」（平均 15、差 3、半分の 1.5 を足して 13.5）
  2. 「山のてっぺんは、次のコマで増える？減る？」
  3. 予想→観察（M01）：「D を2倍にすると？」
  4. 「D × dt = 1.5 にすると何が起きる？」 選んでから実行する
- **クリア:** 4問正解。
- **先生用メモ:** 粒の見方と値の見方が同じことだと腑に落ちたら、2次元へ進んでいい。

### 第4章：記号 ∇² と2次元の拡散

- **ねらい:** ∇²u を「まわりの平均 − 自分」として計算でき、符号の意味がわかる。∂u/∂t = D∇²u が読める。
- **つまずき:** ★T04, T05, T20, T21, ★T07（伏線）
- **たとえ:** A05、A06（砂場）、A14（パックマン）
- **仕掛け:** M03, M01
- **デモ:**
  - 3×3 のマスで、真ん中の ∇² をリアルタイムに表示する。数値を書き換えて試せる。
  - 2次元の草原にインクを1滴落とすと、広がって最後は一様になる。
  - 端に近いインクが反対側から出てくる（パックマン）。
  - カラーバーを表示し、クリックで値が見られる。
- **ドリル例:**
  1. 「真ん中 1、上下左右がすべて 3。∇² は？」（答え +2。谷は埋まる）
  2. 「真ん中 4、まわりが 6, 2, 5, 3。∇² は？」（答え 0）
  3. 地形の絵と ∇² の符号（+、−、0）を線で結ぶ
  4. 予想（M01）：「拡散だけで、このまま待つと模様はできる？」（できない。一様になる → **謎の提示**：「じゃあ模様はどうやってできるの？」）
- **クリア:** 4問正解。
- **先生用メモ:** 「2回微分」という言葉は、本人が聞いてきたら「もっと詳しく」を一緒に読む程度でいい。

### 第5章：反応の項（草とウサギのルール）

- **ねらい:** 式の反応の項それぞれの意味と、増えるか減るかを説明できる。
- **つまずき:** ★T10, T11, T12, T13, T22
- **たとえ:** メインのたとえ、A07（ペアで増える）、A08（満タンまでの残り）、A11（水槽）、A16（お金のやりとり）
- **仕掛け:** M04（項のオン・オフ）、M05（色分け）、M02
- **デモ:** 拡散なし、1か所だけの草原。項を1つずつオンにしていき、u と v の時間変化をグラフで見る。
  1. F(1−u) だけ：草が満タンに向かって伸びる
  2. uv² を追加：ウサギが草を食べて増え、草が減る（移し替え）
  3. kv、Fv を追加：ウサギが減る。F と k の値しだいで、ウサギは全滅するか、草と共存する
- **ドリル例:**
  1. 項と意味を線で結ぶ（4項）
  2. 「u = 0.5、v = 0.4。uv² は？」（答え 0.08）／「ウサギが 0 なら uv² は？」（0）
  3. 「uv² が u の式では −、v の式では + なのはなぜ？」（移し替え）
  4. 予想（M01）：「F を大きくすると、ウサギはどうなる？」
  5. 「F = 0.04 はなぜこんなに小さい？」（1コマあたりの割合だから）
- **クリア:** 5問正解。
- **先生用メモ:** Fv（ウサギも流される）は草とウサギのたとえでは不自然なので、ここだけ水槽のたとえに切り替えると明言する。

### 第6章：全部を合わせる

- **ねらい:** 式全体を、1マスについて手で1コマ進められる。コンピュータは同じ計算を繰り返しているだけだとわかる。
- **つまずき:** T14, ★T01（総まとめ）, T23, ★T07（謎を深める）
- **仕掛け:** M03, M02, M04, M05、電卓
- **デモ:**
  - 色分けしたゴールの式を表示し、項をクリックするとオン・オフが切り替わる。
  - 2次元で全部の項をオンにすると模様が出てくる。拡散だけ、反応だけでは模様が出ないことを、スイッチで確かめさせる。
- **ドリル例（手計算、電卓あり）:**
  - 条件：u = 0.5, v = 0.5, 上下左右の平均 u = 0.6, v = 0.3, Du = 1, Dv = 0.5, F = 0.04, k = 0.06, dt = 1
  - ∇²u = 0.1、∇²v = −0.2、uv² = 0.125、F(1−u) = 0.02、(F+k)v = 0.05
  - ∂u/∂t = 0.1 − 0.125 + 0.02 = −0.005 → 新しい u = 0.495
  - ∂v/∂t = −0.1 + 0.125 − 0.05 = −0.025 → 新しい v = 0.475
  - 各項を埋める穴埋め形式にし、最後にシミュレーションの家計簿と一致することを確かめる。
- **クリア:** 手計算1マス分が正解。
- **先生用メモ:** 小数の計算でつまずいたら、電卓を使っていいと伝える。本題は「どの項を足すか」。

### 第7章：模様ができる理由と、模様の地図

- **ねらい:** 模様ができる理由を説明できる。F-k マップを使って狙った模様を出せる。
- **つまずき:** ★T07（回収）, T08, ★T15, ★T16, T17, T18
- **たとえ:** A09（電車の座席）、A10（火と消防士）、A12（乾燥地の木）、A13（国の地図）
- **仕掛け:** M01, M08, M04
- **前半：謎を解く**
  - ウサギの群れができると、周りの草を食べ尽くす。草は速く広がるので遠くから流れ込んでくるが、その分、少し離れた場所の草が薄くなる。だからすぐ隣には群れが育たず、間隔があく（近くは仲間を増やし、遠くは邪魔をする）。
  - 実験：Du = Dv にすると模様ができない。模様の値ではウサギが全滅し、一面になる値では一色になる（T08。検証済み）。
  - 実験：D を両方とも小さくすると、模様が細かくなる（T15）。
- **後半：模様の地図**
  - F-k マップを「国の地図」として見せる。クリックしたところのパラメータで草原が動く。
  - 同じパラメータで種だけ変えて、模様の種類は変わらないことを確かめる（T17）。
  - 「完成する模様」と「生きている模様」に分ける（T18）。
- **ドリル例:**
  1. 「なぜ模様に間隔があくの？」（選択式。誤答に「拡散が均一にするから」などを仕込む）
  2. 予想：「Du = Dv にすると？」
  3. **この模様を再現せよ**（目標の模様を見せ、つまみやマップで合わせる）
     - 水玉、しま、迷路、分裂する点、穴あき、うずまき
- **クリア:** 理由の問題に正解し、再現チャレンジを3つ以上クリア。
- **自動判定:** パラメータ (F, k) が目標の領域に入っていて、かつ一定時間シミュレーションを回したら合格。
- **先生用メモ:** 電車の座席のたとえは、本人の体験に結びつけやすい。うずまきなど動く模様は種の置き方で出方が変わるので、ヒントで種の置き方も伝える。

### 第8章：自由ラボ

- **ねらい:** 好きな模様を作る。
- **機能:**
  - ブラシで種（ウサギ）を描く、消しゴム、全消し、ランダムに散らす
  - F-k マップをクリックしてパラメータを選ぶ。数値の直接入力、Du・Dv・速さのつまみ
  - 色のパレット（数種類。色覚に配慮したものを含む）
  - 一時停止、1コマ送り、リセット
  - PNG で保存
  - プリセット集（第7章の模様）
  - コレクション：第7章で再現した模様と、自分で作った模様をサムネイル付きで保存し、呼び出せる
- **クリア条件:** なし（自由）。

## 6. 技術

- HTML ファイル1つ（CSS と JS は埋め込み）。外部ライブラリと CDN は使わない（オフラインで動かすため）。
- シミュレーションは JavaScript（Float32Array と Canvas 2D）で、2次元は 128〜256 マス四方。重ければ WebGL 化を検討する。
- 既定値：Du = 1.0、Dv = 0.5。dt は安定条件 Du × dt ≤ 1 を満たす値（例：0.8）を実装時に決める。
- 進み具合、コレクション、設定はブラウザ（localStorage）に保存する。使えない環境でも動作に支障がないようにする。
- スマホ対応：タッチで描ける。横幅 360px でも崩れない。
- ライトモードとダークモードに対応する。
