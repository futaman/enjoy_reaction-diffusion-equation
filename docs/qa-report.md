## 問題なしと確認したこと（主なもの）

- ∇² の定義は全章で「上下左右（1次元は左右）の平均 − 自分」にそろっている（第4章、第5章、家計簿の表示）。∂u/∂t は全章で「変化の速さ（量ではない）」と読ませている。
- 安定条件は第3章（D × Δt < 1、ちょうど 1 は揺れが続く）、第8章（D の上限 1.2 → D × dt = 0.96）、param-report.md で一致している。
- Du = Dv の結果は「全滅（草だけ）／一色」（第7章、`more`）、分裂する点は「画面がうまると止まる」（第7章の注意、patterns.js の `kind: 'still'`）、動き続けるのはうずまき・波だけ。どれも param-report.md と一致する。
- T07 の謎は、第4章で出す（`mystery`）→ 第5章で受ける → 第6章で深める → 第7章で答える、の流れでつながっている。「第N章で学んだ」の参照先も全部正しい。
- 各章の「問題N」の番号（予想と問題が通し番号）と、先生用メモの「問題3で…」などの参照は一致している。
- 項の色（青・緑・オレンジ・紫）は、式・家計簿・本文で一貫している（第2章の速さの地図だけ、低で指摘したとおり例外）。
- 暗いモードでは、本文・ヒント・家計簿・地図の見本は読める（地図の軸の名前だけ、低で指摘したとおり例外）。
