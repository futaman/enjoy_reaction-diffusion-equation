# デザインと雰囲気の仕様

このドリルの「雰囲気」を、作る人が変わっても保てるように言葉にしたものです。
見た目の値の正本は `src/styles/base.css`（デザイントークン）で、この文書はその意図と使い方を書いています。

---

## 1. ひとことで言うと

**「先生が方眼ノートに描いてくれる、ていねいな説明」**

- 落ち着いたノート風。派手なゲームにはしない。
- それでも「動かすと楽しい」「クリアするとうれしい」は、きちんとある。
- 主役は文字ではなく、**動く草原と、自分の手で計算した数字**。

### 大事にしていること

| 言葉 | 意味 |
|---|---|
| やさしい | 中学生が一人で読んでも置いていかれない。急に難しい言葉を出さない |
| ていねい | 1つのページで新しいことは1つだけ。式は1項ずつ組み立てる |
| さわれる | 説明のすぐ横に、触って確かめられるデモがある |
| 正直 | たとえ話の限界は「ここだけ別のたとえに切り替えます」と明かす。数値はすべて検証済み |
| 静かにうれしい | 正解やクリアは、短い言葉とチェックマークで祝う。紙吹雪や効果音は使わない |

## 2. 見た目

### 2.1 紙と罫線

- 背景は**生成り色の紙**（`--paper`）に、**24px 方眼のうすい青い罫線**を敷く。方眼ノートに描いているイメージ。
- 説明やデモは、白いカード（`--card`）にうすい枠線と、ほんのわずかな影を付けて置く。紙の上に付箋やプリントを貼った感じ。
- 角は丸め（10px）。とがった印象を避ける。

### 2.2 色

**基本の色**

| 役割 | トークン | 使いどころ |
|---|---|---|
| 紙 | `--paper` | ページの背景 |
| カード | `--card` / `--card-2` | デモ、問題、表 |
| 文字 | `--ink` / `--ink-2` / `--ink-3` | 本文、補足、目立たない注記 |
| 罫線・枠 | `--line` | カードの枠、表の線 |
| アクセント（青インク） | `--accent` | 主ボタン、章番号、強調の枠。**1画面に多用しない** |
| 正解 | `--ok` | 正解、クリア |
| まちがい | `--ng` | 誤答、注意 |
| ヒント（黄） | `--hint` | ヒントの帯 |
| 先生用（紫） | `--teacher` | 先生用メモ |

**式の項の色（このドリルの背骨）**

式の各項には、いつも同じ色を付けます。文章の中でも、デモのメーターでも、家計簿の表でも同じです。色を見ただけで「どのルールの話か」がわかることが目標です。

| 項 | 色 | トークン | 草とウサギでいうと |
|---|---|---|---|
| D∇²u, D∇²v | 青 | `--t-diff` | 広がる |
| F(1−u) | 緑 | `--t-feed` | 草が生える |
| uv² | オレンジ | `--t-react` | ペアで食べて増える |
| (F+k)v | 紫 | `--t-decay` | ウサギが減る |
| u（草） | 緑 | `--t-u` | 🌱 |
| v（ウサギ） | 茶 | `--t-v` | 🐇 |

- 第1章の帳簿では「速さ（変化）＝オレンジ、量（残高）＝緑」で区別している。変化と量を色で分けるのは、つまずき T01 の対策。
- 新しい色を足すときは、上の役割と重ならないか確認する。

**草原の色（パレット）**

- 既定は「草とウサギ」（緑の草原 → 茶色のウサギ）。ウサギが濃いところほど茶色になる。
- 色覚に配慮した「みどり〜きいろ」（viridis 系）を必ず選べるようにする。
- 色は1つの数（ふつうはウサギの濃さ v）を表す。そのことを、カラーバーの見出しで毎回明記する（T21）。

### 2.3 文字

- 本文はゴシック体（ヒラギノ角ゴ、Noto Sans JP など。端末に入っているものを使い、外部フォントは読み込まない）。
- **式の文字だけは明朝・セリフ体のイタリック**にして、本文と見分けやすくする（`.math`）。
- 分数（∂u/∂t）は横書きにせず、上下に積む（`frac()`）。教科書と同じ見た目にする。
- 行間は広め（1.85）。スマホでは本文を少し小さくする（15.5px）。

### 2.4 明るさ（ダークモード）

- 端末の設定に合わせて自動で切り替える。ヘッダーのボタンで「自動 / 明るい / 暗い」を選べる。
- 暗いときも方眼ノートの雰囲気は残す（罫線をさらにうすく）。項の色は明るめにして、読みやすさを保つ。

## 3. ページの組み立て

### 3.1 章の流れ

すべての章は、同じ順で並びます。いつ開いても「どこに何があるか」がわかるようにするためです。

1. 章番号とタイトル
2. **この章のねらい**（1行）と、クリアまでの問題数
3. ステップの積み重ね（解説 → デモ → 問題）
4. 次の章への橋渡し（1〜2行。謎を残すことが多い）
5. 先生用メモ（折りたたみ）
6. 前へ / もくじ / 次へ

### 3.2 ステップ

- PC では**左に解説、右にデモ**の2カラム。デモは画面にくっついて、読み進めても見え続ける。
- スマホでは縦に並ぶ。そのため本文で「右のデモ」とは書かず、「このデモ」「下のデモ」などとも書かない（位置に頼らない言い方にする）。
- 1つのステップで言うことは1つだけ。見出しは「〜してみよう」「〜とは？」のような、話しかける言い方にする。

### 3.3 囲みの使い分け

| 囲み | 見た目 | 使いどころ |
|---|---|---|
| ポイント | 青い左線 | 覚えてほしい1文 |
| お話 | 緑の左線 | 草とウサギの物語、歴史の話（チューリング、近藤さん） |
| 注意 | 赤の左線 | よくあるまちがい、壊れる条件 |
| 謎 | 紫の左線 | 次の章へ持ち越す問い（「じゃあ模様はどうやってできるの？」） |
| もっと詳しく | 点線の折りたたみ（＋） | 厳密な話、補足、たとえの切り替え。先生がいるときは閉じたままでよい |
| 先生用メモ | 紫の折りたたみ（📝） | つまずき ID、問いかけの例、よくある反応 |

## 4. 言葉づかい

### 4.1 基本

- です・ます調。中学生に、となりで話しかけるように書く。
- 1段落は2〜3文まで。長くなったら分ける。
- 難しい言葉は、すぐ後ろで言い換える。例：「拡散（かくさん）＝広がること」
- 記号は、その章で初めて出るものだけ導入する。読み方も添える（∂ は「ラウンド」、∇² は「ナブラ2乗」）。

### 4.2 草とウサギ

- 物質の話は、最後まで「草（u）」と「ウサギ（v）」で語る。
- 絵文字は 🌱 と 🐇 を中心に、要所だけで使う。1段落に何個も並べない。
- たとえを切り替えるとき（Fv だけは水槽のかけ流し）は、「ここだけ別のたとえを使います」と先に言う。

### 4.3 問題とフィードバック

| 場面 | 言い方の例 | 気をつけること |
|---|---|---|
| 正解 | 「正解です！」「その通り！」＋解説 | 短く祝って、すぐ「なぜ正しいか」を書く |
| まちがい | 「ちがうようです。」＋その選択肢がなぜ違うか | 責めない。誤答ごとに理由を返す（M09） |
| おしい | 「おしい！ ＋と−をもう一度確認しましょう」 | 符号だけ違うなどは、そこを指さす |
| 予想が外れた | 「予想とちがいましたね。でも、予想してから見ることが大事です」 | 予想問題は外れても失敗ではない |
| ヒント | 3段階：考え方の向き → 途中の式 → 答えの手前 | いきなり答えを出さない。最後に「答えを見る」 |
| クリア | トースト「🎉 この章をクリアしました！」と ✓ | 一度だけ、控えめに |

## 5. 動きと手ざわり

- **デモは開いた瞬間から動いている**か、▶ ひとつで動く。白紙から長く待たせない（プロローグは少し先まで計算してから見せる）。
- 再生バーは、どのデモでも同じ並び：▶ 再生 / 1コマ進める / ↺ はじめから / 速さ。
- **1コマ送り**を必ず用意する。速い動きを止めて、数字と見比べられるようにする（M06）。
- マスをクリックすると、そのマスの値が出る。どこでも「さわれば数字が見える」ようにする（T02）。
- 画面の外に出たデモは自動で止める（電池と動作の重さへの配慮）。
- わざと壊すデモは、壊れても「↺ はじめから」で必ず戻れるようにする。
- アニメーションの演出（フェード、バウンドなど）は付けない。動くのはシミュレーションだけ。

## 6. ゲームっぽさの度合い

入れるもの：
- 章ごとのクリア（✓）と、「クリアまで：2 / 4 問」の表示
- もくじの「つづきから」
- 模様のコレクション。まだ再現していない模様は「？」で見せて、集めたくなるようにする

入れないもの：
- 点数、ランキング、制限時間、ライフ
- 効果音、紙吹雪、キャラクターのセリフ演出
- クリアしないと先に進めない仕組み（どの章からでも開ける）

## 7. 使いやすさの約束

- 横幅 360px のスマホでも、横スクロールが出ない。
- ボタンは指で押しやすい大きさ（高さ 38px 前後）にする。
- 色だけに頼らない。正解や誤答は、色に加えて文字（✓、「ちがうようです」）でも伝える。
- キーボードでも操作できる（式の項は Enter でオン・オフ）。
- 動きを減らす設定の端末では、スクロールの演出を止める。
- 外部のフォントやライブラリを読み込まない。ファイル1つで、オフラインで動く。
